# Безопасность

OAuth-токены и полный идентификатор аккаунта хранятся в DSH Credential Store, а не в настройках плагина. Настройки содержат метку, способ входа, ссылку на запись в хранилище, параметры моделей и автообновления лимитов. Клиент не получает токены и полный идентификатор аккаунта.

Вставляйте URL обратного вызова OAuth только в диалог входа, если он его запрашивает. Не отправляйте этот URL или токены в чат, логи и отчеты об ошибках. Запросы каталога и лимитов используют учетные данные соответствующего аккаунта на Host.

Плагин использует сетевой маршрут DSH. Он не предоставляет собственного переключателя прокси и не меняет глобальный `fetch`.
