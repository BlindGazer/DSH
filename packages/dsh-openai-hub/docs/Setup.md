# Установка и приемка

## Требования

- DeepSeek Harness `>=0.2.2-rc.1` с совместимыми host-зависимостями пакета.
- Node.js `>=22.19.0` для установки через CLI.
- Аккаунт ChatGPT с доступом к Codex и поддерживаемым способом OAuth.

Плагин регистрирует ровно один LLM-маршрут `openai-hub` с группой провайдера `OpenAI Hub`. Не регистрируйте другой adapter на этом маршруте. Ключ Remote-сервиса — `openai-hub`, namespace — `openaiHub`; это не дополнительные маршруты провайдера.

## Установка или обновление

Для профиля Web:

```sh
dsh plugin --profile web add @kalex/dsh-openai-hub
```

До публикации нового имени в registry используйте собранный локальный каталог (из корня репозитория):

```powershell
dsh plugin --profile desktop add ./packages/dsh-openai-hub
```

Перезапустите DSH, если этого требует установленная версия. Отдельную desktop-установку обслуживайте через ее менеджер плагинов или CLI приложения.

## Переустановка после legacy-пакета

Автоматический перенос legacy-пакета и конфигурации не гарантируется.

1. Сохраните резервную копию нужных настроек профиля.
2. В каждом установленном профиле выйдите из старого плагина и удалите его, используя точный идентификатор legacy-пакета.
3. Установите новый пакет:

   ```sh
   dsh plugin --profile web add @kalex/dsh-openai-hub
   ```
4. При необходимости перезапустите DSH. Откройте Settings -> Models, задайте каждому аккаунту уникальную метку из строчных ASCII-букв/цифр/дефисов до OAuth и выполните вход заново.
5. Проверьте каталог и лимиты по списку ниже. Не рассчитывайте на перенос старых учетных данных или настроек аккаунта.

Удалить новый пакет из Web-профиля:

```sh
dsh plugin --profile web remove @kalex/dsh-openai-hub
```

Desktop-копию нужно удалять отдельно через соответствующий менеджер/CLI.

## Ручной приемочный список

- [ ] Зарегистрирован только маршрут `openai-hub`, группа провайдера — `OpenAI Hub`.
- [ ] Добавлены два аккаунта с разными допустимыми метками до OAuth; показаны обе карточки и отдельные модальные окна моделей.
- [ ] Модели имеют вид `<label>/<upstreamModelId>`, запрос передает исходный upstream ID; переименование меняет публичные ID, но не credential record.
- [ ] Обновление каталога работает; при ошибке сохраняется последний успешный каталог, а до первого успеха показывается локальный каталог с ошибкой обновления.
- [ ] Автообновление лимитов по умолчанию выключено и сохраняется по аккаунтам: 5 минут обычно, 1 минута для выбранной модели при ближайшем применимом остатке ниже 25%; приоритет окон — час, 5 часов, день.
- [ ] Скрытая страница не отправляет запросы; после возврата выполняется одно обновление нужного аккаунта. В чате лимит относится только к выбранной модели OpenAI Hub.
- [ ] Удаление одного аккаунта не меняет другой и не переписывает историю; удаление последнего возвращает начальный экран добавления.
- [ ] Секреты и полные account ID отсутствуют в UI, конфигурации, логах, ошибках и клиентских снимках.
- [ ] В светлой и темной теме виден фон всех модальных окон OpenAI Hub (модели, подтверждения удаления/сброса) и workspace-manager (`addir-modal`). После пересборки обновите существующую страницу DSH.
- [ ] Browser OAuth завершается локальным callback на машине DSH; для удаленного/headless Host используйте device code. Не проверяйте это реальными токенами в автоматических тестах.

Реальную приемку с аккаунтом выполняет пользователь. Автоматические тесты должны использовать только синтетические данные OAuth/сети.
