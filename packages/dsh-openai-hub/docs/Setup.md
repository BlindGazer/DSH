# Установка и проверка

Требуются DSH `>=0.2.2-rc.5`, Node.js `>=22.19.0` для установки через CLI и аккаунт ChatGPT с доступом к Codex.

## Из GitHub

В DSH Desktop откройте менеджер плагинов и добавьте источник `github:BlindGazer/DSH#path:packages/dsh-openai-hub`. Для отдельного CLI-профиля (например, `web`):

```powershell
dsh plugin --profile web add github:BlindGazer/DSH#path:packages/dsh-openai-hub
```

## Из локальной копии

Из корня репозитория выполните:

```powershell
pnpm install
pnpm --filter @kalex/dsh-openai-hub build
dsh plugin --profile web add C:/git/DSH/packages/dsh-openai-hub
```

Для Desktop выберите собранный локальный пакет в менеджере плагинов вместо последней команды. Перезапустите DSH, если это требуется после установки.

## Переход со старого плагина OpenAI Codex

Сохраните нужные настройки профиля, выйдите из старого плагина и удалите его из профиля. Установите OpenAI Hub и войдите заново. Перенос учетных данных и настроек не гарантируется. Удаление или установка в одном профиле не меняет другой профиль.

## Ручная проверка

1. В настройках моделей добавьте два аккаунта с разными метками. Убедитесь, что в группе `OpenAI Hub` модели отображаются как `<метка>/<ID модели>` и в карточке каждого аккаунта открывается свой список моделей.
2. Обновите каталог. При ошибке обновления предыдущий каталог остается доступным; до первой успешной загрузки используется локальный каталог.
3. Включите автообновление лимитов для одного аккаунта. Проверьте, что в чате показываются лимиты аккаунта выбранной модели OpenAI Hub.
4. При смене метки выберите модель заново. После удаления одного аккаунта каталог второго должен остаться доступным; при удалении последнего должно снова появиться предложение добавить аккаунт.

Для реального входа используйте DSH вручную. Автоматические тесты не требуют настоящих токенов.

## Команды пакета

Из каталога пакета: `pnpm run build` собирает плагин; `pnpm run build:host`, `pnpm run build:client` и `pnpm run build:remote` собирают отдельные части. `pnpm run test` запускает тесты, `pnpm run verify` проверяет артефакты. `pnpm run check` выполняет сборку, тесты и проверку артефактов.
