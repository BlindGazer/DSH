# Примеры в DSH

## Модели двух аккаунтов

Пусть аккаунты имеют метки `work` и `personal`. Их модели отображаются в одной группе провайдера `OpenAI Hub`, например `work/gpt-6.2-sol` и `personal/gpt-6-astra`. У каждого аккаунта своя карточка и модальное окно настроек моделей. Запрос к `work/gpt-6.2-sol` использует credential аккаунта `work` и отправляет upstream-модель `gpt-6.2-sol`.

## Добавление аккаунта

1. Откройте Settings -> Models и нажмите добавление аккаунта.
2. До OAuth укажите уникальную метку из строчных ASCII-букв, цифр и дефисов.
3. Завершите показанную авторизацию ChatGPT.
4. Проверьте модели аккаунта и при необходимости обновите каталог.

Каталог загружается через авторизованный API. Если обновление завершается ошибкой, используется последний успешный каталог; до первой успешной загрузки применяется локальный каталог с отображением ошибки.

## Лимиты

Автообновление лимитов для каждого аккаунта изначально выключено. При включении опрос обычно идет раз в пять минут; для выбранной модели аккаунта интервал сокращается до минуты, если ближайший применимый лимит ниже 25%. Пока страница DSH скрыта, опрос остановлен; после возврата выполняется одно обновление. Статус-бар чата показывает лимиты выбранного аккаунта только для модели OpenAI Hub.

Инструкции по переустановке и ручной приемочный список: [Установка](Setup.md).
