# Возможности

## Аккаунты и вход

Добавьте аккаунт в Settings -> Models. До запуска OAuth укажите уникальную метку из строчных ASCII-букв, цифр и дефисов. Метку можно изменить в карточке аккаунта.

## Общий каталог моделей

OpenAI Hub регистрирует один статический маршрут `openai-hub` в группе провайдера `OpenAI Hub`. После входа и при ручном обновлении загружается авторизованный API-каталог; модели всех аккаунтов объединяются под ID/именем `<меткаАккаунта>/<upstreamModelId>`. При запросе определяется credential нужного аккаунта и передается исходный upstream ID. При ошибке обновления сохраняется последний успешный каталог; до первого успеха используется локальный каталог `pi-ai` с отображением ошибки.

Для каждого аккаунта показываются отдельная информационная карточка и модальное окно моделей. Переименование метки пересобирает публичные ID; старые ссылки в истории устаревают, сама история не переписывается.

## Лимиты и обновление

Лимит отображается только для выбранной модели OpenAI Hub и ее аккаунта; для другого провайдера или устаревшей модели блок скрыт. Автообновление лимитов хранится отдельно для каждого аккаунта и по умолчанию выключено. При включении обновление обычно выполняется раз в пять минут. Для выбранной в чате модели интервал становится минутным, если ближайший применимый лимит ниже 25%. Приоритет окон: час, затем пять часов, затем день. Пока страница DSH скрыта, запросы приостанавливаются; при возвращении выполняется одно обновление.

## Удаление аккаунта

Удаление очищает Credential Store, настройки и модели только этого аккаунта, не переписывая историю диалогов. Удаление последнего аккаунта возвращает начальный экран добавления.

## Сеть и ограничения

Сетевой маршрут задается конфигурацией DSH. В плагине нет выбора proxy-режима или собственного proxy-механизма. Автоматические проверки используют синтетические OAuth/сетевые данные; реальную приемку выполните вручную по [инструкции](Setup.md).
