# Возможности

## Аккаунты и вход

Добавьте аккаунт в Settings -> Models. До запуска OAuth укажите уникальную метку длиной от 1 до 32 символов: начните со строчной латинской буквы, затем используйте строчные латинские буквы, цифры или дефисы. Метку можно изменить в карточке аккаунта. Войти можно через браузер или по коду устройства. Если диалог входа через браузер запрашивает URL обратного вызова, вставьте полный URL перенаправления только в этот диалог.

## Общий каталог моделей

OpenAI Hub регистрирует один статический маршрут `openai-hub` в группе провайдера `OpenAI Hub`. После входа и при ручном обновлении плагин загружает каталог через API от имени аккаунта. ID и имена моделей имеют формат `<метка>/<исходный ID>`. При запросе к модели плагин использует учетные данные соответствующего аккаунта и отправляет исходный ID модели. При ошибке обновления сохраняется последний успешный каталог; до первого успеха используется локальный каталог `pi-ai` с отображением ошибки.

Для каждого аккаунта показываются отдельная информационная карточка и модальное окно моделей. Переименование метки пересобирает публичные ID; старые ссылки в истории устаревают, сама история не переписывается.

## Лимиты и обновление

Лимит отображается только для выбранной модели OpenAI Hub и ее аккаунта; для другого провайдера или устаревшей модели блок скрыт. Автообновление лимитов хранится отдельно для каждого аккаунта и по умолчанию выключено. При включении обновление обычно выполняется раз в пять минут. Для выбранной в чате модели интервал становится минутным, если ближайший применимый лимит ниже 25%. Приоритет окон: час, затем пять часов, затем день. Пока страница DSH скрыта, запросы приостанавливаются; при возвращении выполняется одно обновление.

## Удаление аккаунта

Удаление очищает Credential Store, настройки и модели только этого аккаунта, не переписывая историю диалогов. Удаление последнего аккаунта возвращает начальный экран добавления.

## Сеть и структура

Плагин использует сетевой маршрут DSH и не настраивает прокси самостоятельно.

- `src/shared/`: TypeScript-модели аккаунтов, схема обмена с Host и локализация.
- `src/host/`: плагин Cordis, OAuth, каталог моделей, лимиты и адаптер pi-ai.
- `src/client/`: настройки и индикатор лимитов в React. Для сборки используется Vite, для тестов - Vitest.
