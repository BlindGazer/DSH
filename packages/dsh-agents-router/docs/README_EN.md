A DeepSeek Harness plugin that loads project rules and skills based on routing settings. For example, you can activate React rules when working with files under `src/front/`.

## Installation

**DSH Desktop:** open **Plugins**, select **Add plugin**, and paste: `github:BlindGazer/DSH#path:packages/dsh-agents-router`.

**Terminal:** replace `web` with your CLI profile name. The Desktop app manages the `desktop` profile.

```powershell
dsh plugin --profile web add github:BlindGazer/DSH#path:packages/dsh-agents-router
```
