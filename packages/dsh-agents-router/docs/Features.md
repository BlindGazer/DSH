# Возможности и архитектура

## Что делает плагин

`@kalex/dsh-agents-router` - плагин DeepSeek Harness, который управляет загрузкой инструкций проекта в контекст агента. Вместо того чтобы грузить все правила проекта целиком, он выбирает только те, которые относятся к текущей задаче.

Плагин решает две проблемы:

1. **Перегрузка контекста (context window bloat)**: агент, работающий с back-end, не должен читать правила front-end и наоборот.
2. **Забывчивость**: агент, работающий с файлами OpenSpec, должен автоматически получать правила для работы с ними.

## Как работает

1. При создании агента плагин привязывает сессию к корню проекта (`cwd`).
2. Сканирует проект и обнаруживает правила (`.md`) и навыки (`SKILL.md`) в зонах ответственности.
3. Определяет зоны из `agents/dsh/agents-router.json` (пути и ключевые слова).
4. С учётом активных файлов и рабочего набора сессии выбирает релевантные правила и навыки.
5. Подгружает их в системный промпт агента как отдельные контексты (`areas` и `rules`).

## Зоны ответственности

Зоны задаются в `agents/dsh/agents-router.json`. Для каждой зоны указываются пути и ключевые слова:

```json
{
  "areas": {
    "front": {
      "path": "src/front/",
      "keywords": ["front", "javascript", "react"]
    },
    "front/admin": {
      "path": "src/front/admin/"
    },
    "back": {
      "path": ["src/api/", "src/core/"],
      "enabled": true
    }
  }
}
```

Правила и навыки зоны активируются, когда агент работает с файлами по указанным путям или упоминает ключевые слова в задаче. Зоны могут быть вложенными (`front` и `front/admin`).

## Режимы активации правил

- `always` - правило применяется всегда.
- `glob` - правило применяется по glob-паттерну из frontmatter (`glob`, `globs`, `path`, `paths`, `alwaysApply`).
- `agent-requested` - правило подключается по запросу агента.
- `manual` - правило включается вручную.

## Мягкий бюджет токенов

Плагин оценивает объём инструкций в токенах и соблюдает мягкий бюджет (`tokenBudget`, по умолчанию 16000). Метрики отображаются в панели роутера и во вкладке «Память».

## Изоляция инструкций

- Перенаправление корневых файлов инструкций (`AGENTS.md` и др.) в структуру `agents/`.
- Перенаправление каталогов инструкций (`.cursor`, `.claude`) в `agents/`.

## Диагностика

- Вкладка диагностики показывает, какие правила активны, откуда загружены и почему.
- Для каждого файла можно запустить диагностику пути и увидеть, какие правила применяются.

## Журнал аудита

Плагин ведёт журнал событий маршрутизации: инициализация сессии, сборка промпта, изменения рабочего набора. Журнал можно посмотреть и очистить в интерфейсе.

## Настройки проекта

Управляются в настройках плагина (страница «Плагины»):

- `instructionsRoot` - корень инструкций (`agents`).
- `discoveryMode` - режим обнаружения (`strict`, `fallback`, `merge`).
- `rulesFolder` - папка правил (`rules`).
- `skillsFolder` - папка навыков (`skills`).
- `mainFile` - главный файл инструкций (`agents.md`).
- `tokenBudget` - мягкий бюджет токенов.
- `projectLogging` - логирование проекта.
- `redirectRootInstructionFiles` - перенаправлять корневые файлы инструкций.
- `redirectInstructionDirectories` - перенаправлять каталоги инструкций.
- `logCategories` - категории журнала (события, workset, diff правил, preflight).

## Глобальные настройки

- `locale` - локаль (`auto`, `ru`, `en`).
- `theme` - тема (`auto`, `dark`, `light`).
- `pollingIntervalMs` - интервал опроса (2000, 3000, 5000, 10000).
- `globalLogging` - глобальное логирование.

## Технологический стек

- **TypeScript >= 7.0.2** со строгой типизацией (запрещены `any`, `unknown`, `null`).
- **React 19.3** + **React Compiler** (Vite 8 + Oxc).
- **Vite 8.3.5** (`minify: 'oxc'`).
- **Vitest 3.2.0** для тестов.
- **Biome** и **Oxlint** для линтинга и форматирования.
- **Cordis** (`@deepseek-ai/cordis`) - среда плагинов DSH.
- **YAML** - парсинг frontmatter и конфигурации зон.

## Архитектура

Трёхслойная модульная архитектура:

- `src/shared/` - модели, константы, валидаторы, локализация (без Node.js и React).
- `src/host/` - серверная логика: обнаружение правил, выбор, изоляция, API `/agents-router`.
- `src/client/` - React UI: настройки, панель роутера, диагностика, каталог, память.

Зависимости направлены только `shared -> host/client`. `host` не импортирует `client` или React.
