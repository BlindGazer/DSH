# [@kalex/dsh-agents-router](https://github.com/BlindGazer/DSH)

> [GitHub BlindGazer/DSH](https://github.com/BlindGazer/DSH)

A **DeepSeek Harness (DSH)** plugin that routes relevant project rules, skills, and instructions into the agent context.

## Purpose

Helps prevent context overload by selecting instructions based on active files and the session's working set.
