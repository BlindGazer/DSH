---
description: Language and communication style, reply to the user in Russian with short clear phrases, one question per message, options with consequences and a recommendation
---

- Reply to the user in Russian with short clear phrases. But when there are important remarks or consequences, mention them.
- Ask no more than one question per message.
- When offering a choice, give options, their consequences and a preferred option.
- Move from familiar context to new context without skipping steps in meaning.
- Code comments explain the reason and boundaries of the solution, also in Russian.
- For any text you write, follow `agents/rules/no-fancy-symbols.md`.
