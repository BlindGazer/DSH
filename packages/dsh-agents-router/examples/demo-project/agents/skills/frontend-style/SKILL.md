# Frontend style guide

Use design-system components. Screenreader support is out of scope; do not add screenreader-only names, roles, or informational ARIA. Preserve external host DOM contracts and functional attribute consumers.

## Key principles

- Use semantic HTML elements
- Ensure keyboard navigation
- Preserve visible labels, focus treatment, and native functionality
- Maintain sufficient color contrast
