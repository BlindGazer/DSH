# [@kalex/dsh-agents-router](https://github.com/BlindGazer/DSH)

> [GitHub BlindGazer/DSH](https://github.com/BlindGazer/DSH)

Плагин для **DeepSeek Harness (DSH)**, который подключает к контексту агента подходящие правила, навыки и инструкции проекта.

## Назначение

Помогает избежать перегрузки контекста: выбирает инструкции с учетом активных файлов и рабочего набора сессии.
