# Установка и команды

## Требования

- DeepSeek Harness `>=0.2.2-rc.1` и совместимые host-зависимости из `package.json`.
- Node.js `>=22.19.0` для CLI-установки.
- Учетная запись ChatGPT с доступом к Codex и поддержкой входа по коду устройства.

Используйте только одну реализацию маршрута `openai-codex`. Одновременная регистрация другого провайдера для этого маршрута, включая встроенную реализацию DSH, может вызвать конфликт и помешать активации плагина.

## Установка или обновление

Для профиля Web выполните:

```sh
dsh plugin --profile web add @kalex/dsh-openai-codex-provider
```

После обновления перезапустите DSH, если этого требует установленная версия. Для отдельного desktop-профиля используйте менеджер плагинов или CLI, поставляемый с этой версией приложения.

## Сборка из исходников

```sh
# Сборка плагина (Host + Client)
pnpm run build

# Сборка только клиентской части
pnpm run build:client

# Сборка только серверной части
pnpm run build:host

# Сборка удаленной части
pnpm run build:remote

# Запуск модульных тестов
pnpm run test

# Проверка артефактов плагина
pnpm run verify

# Полная проверка: сборка + тесты + verify
pnpm run check
```

## Удаление

Сначала выйдите из учетной записи в настройках OpenAI Codex, чтобы удалить локальные учетные данные, затем удалите пакет из профиля Web:

```sh
dsh plugin --profile web remove @kalex/dsh-openai-codex-provider
```

Для desktop-профиля удаление выполняйте через соответствующий менеджер или CLI приложения. Удаление из Web не удаляет отдельную копию desktop.
