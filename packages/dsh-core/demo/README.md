# Демо @kalex/dsh-core

Запустите отдельный Vite стенд из корня монорепозитория:

```sh
pnpm --filter @kalex/dsh-core demo
```

Перед запуском команда проверяет `master` репозитория `deepseek-ai/deepseek-harness` и обновляет кэш официальных DSH-стилей в `node_modules/dsh-github-styles` только при изменении SHA. При недоступном GitHub используется существующий кэш.

Vite выведет локальный URL в терминал. На странице показаны экспортируемые компоненты Core, переключение светлой/темной темы, интерактивные элементы и состояния disabled.
