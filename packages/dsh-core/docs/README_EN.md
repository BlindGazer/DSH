> [GitHub BlindGazer/DSH](../../../README.md)

A library of React components, themes, hooks, and utilities for DeepSeek Harness (DSH) plugins. Plugins can share buttons, inputs, and loading indicators, for example.

This is not a DSH plugin. To use it in an external project, build the library and install its archive as described below. The archive includes JavaScript, styles, and TypeScript declarations.

Stack: TypeScript, React, Sass, Vite, and Vitest.
