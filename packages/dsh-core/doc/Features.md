# Возможности

## Что предоставляет

Общую дизайн-систему, UI-компоненты, темы, хуки и утилиты для плагинов DSH, чтобы плагины не дублировали базовую логику и выглядели единообразно.

## Компоненты

- `Button`, `IconButton` - кнопки и кнопки-иконки.
- `ThemedSelect` - темизированный выпадающий список.
- `SwitchControl` - переключатель.
- `Tabs` - вкладки.
- `Modal` - модальное окно.
- `Skeleton`, `Spinner`, `ProgressBar`, `ChildrenLazy` - состояния загрузки.

## Темы

Единые CSS-переменные `--dsh-ui-*` для поверхностей, текста, границ, возвышений и семантических состояний (`info`, `success`, `warning`, `danger`). Поддержка светлой, темной и пользовательских тем. Функция `buildCoreThemeStyles` генерирует стили темы.

## Хуки

- `useDebouncedValue` - дебаунс значения.
- `useLocalePreference` - предпочтение локали.
- `useEffectiveTheme` - эффективная (актуальная) тема.
- `useDshThemeRevision` - ревизия темы DSH.

## Утилиты

- `classNames` - объединение классов.
- `formatMessage` - форматирование строк локализации с подстановкой `{0}`, `{1}`.
- `hostSanitizer` - санитизация данных, получаемых от хоста.

## Модели и константы

- `SelectOption`, `ThemePalette`, `DshContext` - общие типы.
- `Delay` - стандартные тайминги анимаций и дебаунса.
- Локализация `CoreLocalization` с поддержкой `ru` и `en`.

## Технологический стек

| Технология | Версия / особенности        |
| ---------- | --------------------------- |
| TypeScript | >= 7.0.2, строгая типизация |
| React      | 19                          |
| Vite (Oxc) | 8.3.5                       |
| Vitest     | 3.2.0                       |

## Архитектура

Пакет не зависит от конкретных плагинов: компоненты, хуки, темы, утилиты и модели изолированы и переиспользуются любым плагином DSH.
