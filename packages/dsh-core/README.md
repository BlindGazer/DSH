Библиотека React-компонентов, тем, хуков и утилит для плагинов DeepSeek Harness (DSH). Например, плагины могут использовать одни и те же кнопки, поля ввода и индикаторы загрузки.

Это не плагин DSH. Для внешнего проекта соберите библиотеку и установите архив по инструкции ниже. В архив входят JavaScript, стили и декларации TypeScript.

Стек: TypeScript, React, Sass, Vite и Vitest.
