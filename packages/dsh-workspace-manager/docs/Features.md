# Возможности

## Что делает плагин

Подключает несколько каталогов (директорий) из разных расположений к рабочему пространству DSH. Каждый каталог получает псевдоним и описание, доступ может быть ограничен режимом только для чтения.

## Зачем нужен

Позволяет работать с проектом, файлы которого разбросаны по нескольким папкам, в одном рабочем пространстве. Помогает отличать каталоги по понятным псевдонимам и защищать их от случайного изменения.

## Как работает

1. Каталог добавляется через меню рабочего пространства (кнопка `...` в боковом меню).
2. В редакторе задаются путь, псевдоним, описание и флаг только для чтения.
3. Плагин регистрирует каталоги в контексте рабочего пространства DSH.
4. Каталоги с флагом только для чтения защищаются от записи.

## Поля каталога

- `path` - абсолютный путь к каталогу.
- `alias` - короткий псевдоним для отображения.
- `description` - необязательное описание.
- `readOnly` - ограничить доступ режимом только для чтения.

## Проверка путей и безопасность

Канонические пути (`realpath`) проверяются на выход за пределы каталога и обход симлинков, чтобы не допустить доступ к посторонним файлам.

## Архитектура

Трехслойная модульная:

1. `src/shared/` - модели и константы.
2. `src/host/` - сервис каталогов, проверка доступа, инструменты путей.
3. `src/client/` - меню и редактор каталогов.
