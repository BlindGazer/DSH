# Возможности

## Подключенные каталоги

В меню рабочего пространства откройте редактор каталогов. Для каждого каталога укажите абсолютный путь на машине DSH Host, псевдоним, необязательное описание и при необходимости включите режим только для чтения.

При проверке доступа плагин учитывает канонические пути, в том числе цели символических ссылок. Плагин отклоняет запись через файловые инструменты DSH в каталог, помеченный как доступный только для чтения. Этот режим не меняет права файловой системы.

## Git worktree

В меню `...` выберите **Новая сессия worktree**. Можно создать ветку от локальной ветки или известной Git ветки удаленного репозитория, открыть свободную локальную ветку или создать отслеживающую ветку из origin, если одноименной локальной ветки нет, или выбрать существующий worktree того же репозитория. Исходная сессия не меняется, незакоммиченные изменения не переносятся.

По умолчанию плагин создает worktree в `.worktrees` рабочего каталога. Базовый путь можно изменить. При создании в стандартном расположении плагин добавляет `/.worktrees/` в `.gitignore`, если Git еще не игнорирует этот каталог.

**Удалить worktree** доступно в меню основной рабочей области при наличии дополнительных worktree. Выберите worktree по ветке и пути. В диалоге можно также запросить слияние и удаление ветки. Архивация сессии не удаляет worktree. Перед удалением перенесите важные файлы, которые Git игнорирует: они не блокируют удаление и могут быть потеряны.

## VS Code

Если действие **Открыть в VS Code** включено в настройках плагина, оно доступно в меню рабочего пространства. VS Code запускается на машине DSH Host; установите его на этой машине.

## Стек и структура

- `src/shared/`: TypeScript-модели и константы.
- `src/host/`: плагин Cordis, управление каталогами, проверка путей и операции Git.
- `src/client/`: меню и диалоги React. Для сборки используется Vite, для тестов - Vitest.
