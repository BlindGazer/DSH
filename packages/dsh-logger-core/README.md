# [@kalex/dsh-logger-core](https://github.com/BlindGazer/DSH/tree/main/packages/dsh-logger-core)

[![TypeScript 7](https://img.shields.io/badge/TypeScript-7-3178C6)](https://www.typescriptlang.org/) [![Vite 8](https://img.shields.io/badge/Vite-8-D97706)](https://vite.dev/) [![license ISC](https://img.shields.io/badge/license-ISC-568814)](https://github.com/BlindGazer/DSH/blob/main/LICENSE.md)

> [GitHub BlindGazer/DSH](https://github.com/BlindGazer/DSH)

Библиотека типов и функций для записи логов из плагинов DeepSeek Harness (DSH) и внешних проектов. Плагин может отправлять записи в `@kalex/dsh-logger`, когда этот сервис доступен, и работать без него.

Библиотека не устанавливается как плагин DSH. Для внешнего проекта соберите архив с JavaScript и декларациями TypeScript и установите его по инструкции ниже.

Стек: TypeScript, Vite и Vitest.
