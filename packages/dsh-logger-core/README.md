# [@kalex/dsh-logger-core](https://github.com/BlindGazer/DSH/tree/main/packages/dsh-logger-core)

> [GitHub BlindGazer/DSH](https://github.com/BlindGazer/DSH)

Библиотека интерфейсов записи логов и адаптеров для плагинов DSH и внешних проектов. Не устанавливается как плагин, не регистрирует сервис и не имеет интерфейса DSH.

Для подключения соберите библиотеку и установите архив, как описано в разделе установки.

Стек: TypeScript, Vite и Vitest. Сборка выпускает JavaScript и декларации `.d.ts`, чтобы внешние TypeScript-проекты могли использовать API без исходников монорепозитория.
