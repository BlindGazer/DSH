# Подключение и команды

Во внешнем TypeScript-проекте используйте собранный архив пакета. Пакет не опубликован в публичном npm.

Внутри монорепозитория одноименный алиас ведет прямо на TypeScript-исходники. Не добавляйте библиотеку в зависимости внутренних пакетов. Команды из корня клона:

```bash
pnpm install
pnpm --filter @kalex/dsh-logger-core build
pnpm --filter @kalex/dsh-logger-core test
pnpm check
```

После сборки выполните `pnpm pack` в каталоге библиотеки. В проекте-потребителе установите архив командой `pnpm add <путь-к-архиву>`. Через DSH CLI библиотека не устанавливается: у нее нет точки входа плагина.
