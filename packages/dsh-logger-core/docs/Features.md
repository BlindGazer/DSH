# Возможности

- `DshLogger.record(record)` принимает запись типа `DshLogRecord` с JSON-совместимыми данными.
- `NOOP_LOGGER` игнорирует все записи.
- `createOptionalLogger(context, packageName)` передает записи в `dshLoggerService`, когда сервис доступен в Host. Пока подключения нет или после его завершения записи отбрасываются, а при повторном подключении снова передаются сервису.
- `createHostLogger` и `createClientLogger` предоставляют методы `debug`, `info`, `warn`, `error`. Клиентский `sink` вызывается даже без получателя.

Библиотека не зависит от Cordis, React или Node.js и не регистрирует сервисы. Она не фильтрует, не санитизирует и не сохраняет записи и не перехватывает ошибки переданного `sink` или получателя. Политика хранения и интерфейс настроек находятся в [плагине логирования](../../dsh-logger/README.md).
