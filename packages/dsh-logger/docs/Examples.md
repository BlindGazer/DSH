# Настройка в DSH

1. В настройках DSH откройте раздел "DSH logger".
2. Включите запись. При необходимости задайте минимальный уровень, каталог и предельный размер файла, затем сохраните настройки.
3. Чтобы задать свой уровень или лимит для пакета, откройте его настройки. В списке видны зарегистрированные пакеты и пакеты с сохраненными настройками, а не все установленные плагины.
4. При смене каталога проверьте список удаляемых файлов в прежнем каталоге. Сохраните нужные логи отдельно перед подтверждением.

По умолчанию файлы находятся в подкаталоге `dsh-logger` каталога профиля. Например, пакет `@kalex/dsh-agents-router` пишет в `@kalex-dsh-agents-router.jsonl`.
