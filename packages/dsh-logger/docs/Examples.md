# Настройка в DSH

1. Откройте настройки DSH и выберите раздел "DSH logger".
2. Включите запись и сохраните настройки. В панели можно задать уровень, каталог и размер файла.
3. Для подключенного пакета откройте его параметры и при необходимости переопределите уровень или лимит. Список показывает зарегистрированные пакеты и сохраненные переопределения, а не все установленные плагины.
4. При смене каталога проверьте список удаляемых файлов в прежнем каталоге. Сохраните нужные логи отдельно перед подтверждением.
