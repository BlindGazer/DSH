# Settings in DSH

1. Open DSH Settings and select "DSH logger".
2. Enable recording and save settings. Set the level, directory, and file size limit in the panel.
3. Open a participating package's settings to override its level or limit. The list shows registered packages and saved overrides, not all installed plugins.
4. When changing directories, review which files will be deleted from the old directory. Back up any logs you need before confirming.
