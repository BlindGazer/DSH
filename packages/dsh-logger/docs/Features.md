# Возможности

Плагин пишет структурированные записи в отдельный файл JSONL для каждого подключенного пакета. Если новая запись не помещается, плагин удаляет самые старые записи, чтобы не превысить лимит файла.

- `shared`: схемы настроек и правила маскирования данных.
- `host`: сервис Cordis `dshLoggerService`, хранение настроек через Config Editor, фильтрация и запись на диск.
- `client`: панель на React для общих настроек и переопределений по пакетам.

В серверной части своего плагина вызовите `createOptionalLogger(context, packageName)` из `@kalex/dsh-logger-core`. Передайте точное имя npm-пакета. Пакет регистрируется даже при выключенной записи. Если он подключился после открытия панели настроек, обновите список.
