# Возможности

Плагин хранит структурированные записи в отдельных файлах JSONL для каждого подключенного пакета. При достижении лимита удаляются самые старые записи.

- `shared`: схемы настроек и правила санитизации.
- `host`: сервис Cordis `dshLoggerService`, настройка через Config Editor, фильтрация и запись на диск.
- `client`: панель DSH на React для общих и индивидуальных параметров.

Для подключения из Host используйте `createOptionalLogger(context, packageName)` из `@kalex/dsh-logger-core`. Передавайте точное имя npm-пакета. Регистрация возможна при выключенной записи; если пакет появился после открытия панели, обновите список. Внутри монорепозитория алиас ведет на исходники библиотеки, а не на установленную копию.
