# [@kalex/dsh-logger](https://github.com/BlindGazer/DSH/tree/main/packages/dsh-logger)

> [GitHub BlindGazer/DSH](https://github.com/BlindGazer/DSH)

A DeepSeek Harness plugin that records and configures logs for participating plugins. Recording is off by default.

```powershell
dsh plugin --profile desktop add github:BlindGazer/DSH#path:packages/dsh-logger
```

Stack: TypeScript, Cordis, React, Vite, and Vitest. No public `.d.ts` files are generated: this is a DSH plugin, not a library. Use `@kalex/dsh-logger-core` for integration.
