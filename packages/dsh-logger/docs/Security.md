# Безопасность логов

Запись по умолчанию выключена. Правила маскирования применяются только к полю `data`. Ключи и пути внутри него можно указать в общих настройках и для отдельных пакетов. Не передавайте в журнал секреты, токены или персональные данные даже при настроенном маскировании. В частности, правила для `data` не защищают поля самой записи, например `event`.

Выбирайте каталог с подходящими правами доступа. Лимит файла ограничивает размер журнала, но не заменяет контроль доступа.
