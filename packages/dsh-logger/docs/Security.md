# Безопасность логов

Запись по умолчанию выключена. Санитизация применяется к полю `data`; можно настраивать ключи и пути на общем уровне и для отдельных пакетов. Не передавайте секреты, токены или персональные данные в журнал. В частности, не помещайте их в `event`, `phase` или `operation`: эти поля не проходят санитизацию `data`.

Выбирайте каталог с подходящими правами доступа. Лимит файла ограничивает размер журнала, но не заменяет контроль доступа.
