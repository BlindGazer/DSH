# [@kalex/dsh-logger](https://github.com/BlindGazer/DSH/tree/main/packages/dsh-logger)

> [GitHub BlindGazer/DSH](https://github.com/BlindGazer/DSH)

Плагин DeepSeek Harness для централизованной записи и настройки логов подключенных плагинов. Запись по умолчанию выключена.

```powershell
dsh plugin --profile desktop add github:BlindGazer/DSH#path:packages/dsh-logger
```

Стек: TypeScript, Cordis, React, Vite и Vitest. Публичные декларации `.d.ts` не генерируются: это плагин DSH, не библиотека. Для интеграции используйте `@kalex/dsh-logger-core`.
