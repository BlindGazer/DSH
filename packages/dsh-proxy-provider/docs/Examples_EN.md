# Examples in DSH

## Plugin settings

The plugin adds a "Proxy for model providers" section to the DSH model-provider settings page.

In this section you can:

- Create and edit proxy profiles (protocol, host, port, username, password).
- Assign a profile to a specific provider or keep direct connection.
- Test the connection and see the latency.

## Proxy profiles

A list of profiles: name, protocol, host, port, authentication status, and action buttons.

## Provider bindings

For each discovered model provider - select a profile from the list or direct connection.

## Import and export

Buttons to import and export profile configuration (passwords are encrypted).
