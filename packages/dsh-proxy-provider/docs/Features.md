# Возможности

## Что делает плагин

Проксирует сетевые запросы выбранных провайдеров моделей DSH через заданные прокси-серверы. Остальные провайдеры работают напрямую.

## Зачем нужен

Помогает обойти сетевые ограничения и блокировки API у отдельных провайдеров (OpenAI, Anthropic, DeepSeek, OpenRouter и других). Позволяет использовать разные прокси для разных провайдеров.

## Как работает

1. Обнаруживает провайдеров моделей DSH и их хосты.
2. Собирает таблицу маршрутизации: сопоставляет хосты провайдеров с профилями прокси.
3. Подменяет диспетчер undici для проксируемых хостов, остальные запросы идут напрямую.
4. Выявляет конфликты доменов между провайдерами.

## Поддерживаемые протоколы

- HTTP
- HTTPS
- SOCKS5

## Профили прокси

Профиль описывает прокси-сервер: `id`, имя, протокол, хост, порт, аутентификацию (логин и пароль) и флаг `ignoreSslErrors`.

## Привязка к провайдерам

Для каждого провайдера можно выбрать профиль прокси или прямое подключение.

## Шифрование учетных данных

Логин и пароль шифруются AES-256-GCM локальным мастер-ключом (подробнее в [Security](Security.md)).

## Проверка соединения

Позволяет проверить доступность прокси и замерить задержку по тестовому URL.

## Импорт и экспорт профилей

Профили можно импортировать и экспортировать, пароли при этом шифруются.

## Архитектура

Трехслойная модульная:

1. `src/shared/` - модели, константы, валидаторы, локализация (без Node.js и React).
2. `src/host/` - сервисы маршрутизации, шифрования, диспетчера, хранения и проверки соединения.
3. `src/client/` - интерфейс профилей и привязок провайдеров.
