# Возможности

## Маршрутизация

В настройках DSH выберите профиль прокси для обнаруженного провайдера моделей или оставьте прямое подключение. Плагин сопоставляет имена хостов провайдера с выбранным профилем и направляет запросы к ним через диспетчер undici. Запросы к хостам без назначенного прокси идут напрямую.

Плагин сначала ищет маршрут для хоста с портом, затем для имени хоста. Если провайдеры используют один адрес назначения с разными настройками, плагин показывает конфликт и выбирает первый назначенный профиль. Маршрут действует и для провайдера, у которого для того же адреса выбрано прямое подключение.

## Профили и проверка соединения

В профиле задаются имя, протокол (HTTP, HTTPS или SOCKS5), хост, порт и, если требуется, логин и пароль. Опцию `ignoreSslErrors` лучше оставить выключенной; см. [Безопасность](Security.md). Проверка соединения отправляет запрос к тестовому URL через выбранный профиль и показывает задержку.

При экспорте учетные данные по умолчанию не включаются. Для их переноса выберите экспорт с учетными данными и задайте пароль шифрования. При импорте такого файла введите этот пароль или пропустите учетные данные.

## Стек и структура

- `src/shared/`: TypeScript-модели, константы, вспомогательные функции и локализация. Интерфейс использует язык DSH.
- `src/host/`: плагин Cordis, маршрутизация через undici, хранение и проверка соединения.
- `src/client/`: интерфейс React для профилей и привязок. Для сборки используется Vite, для тестов - Vitest.
