# Безопасность

## Шифрование учетных данных

Логин и пароль прокси шифруются алгоритмом AES-256-GCM с 256-битным мастер-ключом. Для каждого шифрования используется уникальный вектор инициализации (12 байт).

## Мастер-ключ

Мастер-ключ генерируется автоматически при первом использовании и хранится в `%LOCALAPPDATA%\kalex-dsh-proxy-provider\master.key` с правами доступа `0600`.

## Учетные данные не раскрываются

Клиентский интерфейс получает только обезличенные данные: маску логина и флаг наличия пароля. Открытые пароли не передаются в состояние клиента и не попадают в логи.

## Игнорирование ошибок SSL

Опция `ignoreSslErrors` отключает проверку сертификатов для прокси. Используйте осознанно: это снижает безопасность TLS-соединения.
