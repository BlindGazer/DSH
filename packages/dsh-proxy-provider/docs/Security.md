# Безопасность

Логин и пароль прокси в сохраненной конфигурации шифруются с помощью AES-256-GCM. Для каждого шифрования создается случайный 12-байтный вектор инициализации. Ключ хранится в `%LOCALAPPDATA%/kalex-dsh-proxy-provider/master.key`; если `LOCALAPPDATA` не задана, используется `AppData/Local` в домашнем каталоге. Не передавайте ключ вместе с конфигурацией.

Клиентский снимок настроек содержит маску логина и признак наличия учетных данных, а не исходные значения. Для переноса учетных данных используйте экспорт с отдельным паролем; обычный экспорт их не включает.

`ignoreSslErrors` отключает проверку сертификата HTTPS-сервера при запросах через профиль, а для HTTPS-прокси также проверку сертификата самого прокси. Оставляйте настройку выключенной, чтобы сохранить проверку TLS.
