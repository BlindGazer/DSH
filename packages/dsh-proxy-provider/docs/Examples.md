# Примеры в DSH

1. В настройках моделей откройте раздел прокси для провайдеров моделей.
2. Создайте профиль: укажите имя, протокол, хост и порт. Добавьте учетные данные, если их требует прокси.
3. Запустите проверку соединения и проверьте результат и задержку.
4. Выберите профиль у нужного провайдера. Если два провайдера используют один хост, проверьте, какой профиль указан в сообщении о конфликте.

Чтобы перенести настройки в другой профиль DSH, экспортируйте конфигурацию и импортируйте файл в целевом профиле. Учетные данные включаются только по отдельному выбору и шифруются заданным при экспорте паролем.
