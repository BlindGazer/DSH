# [Proxy provider](https://github.com/BlindGazer/DSH/tree/main/packages/dsh-proxy-provider)

Плагин для **DeepSeek Harness (DSH)**, который направляет сетевые запросы выбранных LLM-провайдеров через заданные прокси.

## Назначение

Позволяет настраивать выборочную маршрутизацию запросов провайдеров через HTTP, HTTPS и SOCKS5 прокси, сохраняя прямое подключение для остальных запросов.
