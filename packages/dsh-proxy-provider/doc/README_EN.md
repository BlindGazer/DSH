# [Proxy provider](https://github.com/BlindGazer/DSH/tree/main/packages/dsh-proxy-provider)

A **DeepSeek Harness (DSH)** plugin that routes selected LLM provider requests through configured proxies.

## Purpose

Enables selective routing of provider requests through HTTP, HTTPS, and SOCKS5 proxies while keeping other requests direct.
