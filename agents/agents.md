# AGENTS

Инструкции для ИИ-агентов проекта ORD. Изменения в код можно вносить напрямую
по требованиям пользователя. Использование OpenSpec необязательно.

## Правила и навыки

Единственное место хранения правил - `agents/rules/`, навыков - `agents/skills/`.
Правила и навыки обязательны для всех агентов
Базовая роль агента [ponytail](/agents/rules/ponytail.md)

## OpenSpec

Основные правила работы с [OpenSpec](/agents/openspec/rules/common.md)

## Постоянные границы проекта

- Перед поиском и чтением файлов учитывай исключения из `.agentignore` если он есть.
- Не добавлять секреты, ключи, токены и реальные строки подключения в репозиторий.
- Коммит, amend, push и PR выполнять только по явной просьбе человека (исключение: при закрытии выполненного пункта в `tasks.md` по OpenSpec агент коммитит изменения этапа через навык [commit](/agents/skills/commit/SKILL.md)). Не обходить
  хуки и не делать force push в `main` или `master`.

## Язык и отчёты

- Используй правила из файла `agents/rules/human-communication.md`.

## Игнорируй

Исключи из поиска и индексации папки и файлы указанные в [.gitignore](/.gitignore)
Если нужен к ним доступ сначала спроси у польователя
