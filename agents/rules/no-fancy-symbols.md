description: "In files, code, comments and documents do not use the em dash, arrows, emoji and other symbols a human normally does not type; they are allowed in chat replies, and when the user explicitly asked or the symbols already exist in the edited text"
---

Do not use the em dash (—), arrows (→), emoji, typographic quotes («» and similar), or a one-character ellipsis. Use ASCII: `-`, `->`, `"`, `'`, `...`. Box-drawing characters in directory trees (├ └ │) are allowed.

**Exceptions:** symbols are allowed in chat replies when the user explicitly allowed them or when they already exist in the text the agent works with (editing an existing file does not require replacing symbols already there).

**Why:** symbols reveal text generated by an AI.
