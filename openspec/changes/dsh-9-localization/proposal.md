# Proposal

## Why

Плагины по-разному выбирают язык. Одни сохраняют язык при запуске, другие позволяют переопределить его. Из-за этого открытый интерфейс не всегда следует настройке DSH.

## What Changes

- Использовать общий типизированный контракт Core поверх штатной локализации DSH без второго хранилища. Словари остаются у владельцев.
- Обновлять открытые представления OpenAI Hub, Agents Router, Proxy Provider, Workspace Manager и Logger при смене языка без потери состояния.
- **BREAKING**: убрать локальный выбор языка Router и Proxy Provider. Старые значения не влияют на интерфейс; остальные настройки сохраняются.

## Capabilities

### New Capabilities
- `plugin-localization`: синхронизация переводов и регионального форматирования с DSH.

### Modified Capabilities
- `theme-consistency`: снять требование ручного выбора языка прокси, заменив его общим правилом.

## Impact

Затронуты dsh-core и пять клиентских пакетов. Текущий пакет для интерфейса Codex - dsh-openai-hub. Изменения среды DSH и библиотеки dsh-logger-core не нужны.
