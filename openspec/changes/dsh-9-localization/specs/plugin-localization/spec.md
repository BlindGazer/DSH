## Purpose

Пользователь управляет языком интерфейсов всех клиентских плагинов в одном месте, в настройках DSH.

## ADDED Requirements

### Requirement: Открытые представления следуют языку оболочки
OpenAI Hub, Agents Router, Proxy Provider, Workspace Manager и Logger MUST обновлять переводы при изменении языка DSH без перезапуска и потери состояния представления.

#### Scenario: Переключение при открытом окне
- **WHEN** пользователь меняет язык DSH с английского на русский или обратно при открытой панели плагина
- **THEN** видимые подписи, подсказки и доступные имена обновляются без повторного открытия, выбранная вкладка и введенные значения сохраняются

#### Scenario: Для языка нет перевода
- **WHEN** активный язык DSH не имеет перевода конкретного ключа плагина
- **THEN** подпись определяется штатной цепочкой резервных языков DSH, а даты и числа форматируются для активной локали независимо от языка найденной строки

### Requirement: Локальный выбор языка отсутствует
Router и Proxy Provider MUST использовать только язык DSH и не предоставлять отдельного поля выбора языка.

#### Scenario: Обновление со старой настройкой
- **WHEN** сохраненный язык плагина отличается от языка DSH и пользователь открывает настройки после обновления
- **THEN** интерфейс следует DSH, поле языка отсутствует, остальные настройки сохраняют значения
