# Proposal

## Why

Роутер сейчас ищет инструкции только в каталоге `agents` внутри workspace. Это не позволяет нескольким проектам использовать общий внешний каталог правил и навыков, например `D:/GIT/Agents/dsh-plugins`, без копирования файлов или перенаправления. Нужен управляемый через UI режим абсолютного корня с сохранением текущего поведения по умолчанию.

## What Changes

- Добавить `resolverMode` со значениями `relative` или `absolute`, по умолчанию `relative`. Он выбирает источник инструкций: workspace или внешний `instructionsRoot`.
- Сохранить `discoveryMode` со значениями `strict`, `merge` и `fallback`. Он определяет способ работы с разрешенными источниками.
- В относительном режиме сохранить текущий поиск инструкций внутри workspace.
- В абсолютном режиме разрешить внешний абсолютный `instructionsRoot`, независимый от workspace.
- В абсолютном режиме разрешить только `discoveryMode = strict` и `discoveryMode = merge`; `fallback` недоступен.
- В `discoveryMode = merge` объединять workspace и внешний `instructionsRoot`; при совпадении правило из внешнего корня имеет приоритет.
- Хранить настройки режима и корня в существующем DSH project store, а не в папке `agents`.
- Разрешать ссылки `@workspace/...` относительно workspace и `@instructions/...` относительно корня инструкций.
- В абсолютном режиме диагностировать неоднозначные старые ссылки и устаревшие пути `/agents/...`.
- Обновить UI, диагностику, документацию и тесты.
- **BREAKING**: в `resolverMode = absolute` внешний каталог является основным источником. При `discoveryMode = strict` используется только он, а при `discoveryMode = merge` он объединяется с workspace; при совпадении внешнее правило имеет приоритет.

## Capabilities

### New Capabilities
- `router-absolute-resolver`: выбор относительного или абсолютного корня инструкций, безопасное обнаружение внешнего каталога и явное разрешение ссылок между корнями.

### Modified Capabilities
- `router-instruction-isolation`: правила перенаправления, защиты корня и отображения инструкций должны учитывать выбранный внешний корень.

## Impact

Затрагиваются модели и валидация настроек `dsh-agents-router`, хранилище проектных настроек, discovery и проверки symlink, обработка ссылок в инструкциях, API состояния роутера, вкладки настроек и диагностики, документация и тесты. Новые зависимости не требуются. Реализация не должна изменять обычную работу проектов в относительном режиме.
