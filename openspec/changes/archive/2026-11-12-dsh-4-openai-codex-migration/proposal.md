# Proposal

## Why

Перенести существующий плагин OpenAI Codex из отдельного репозитория в монорепозиторий DSH, чтобы развивать и проверять его по стандартам проекта. Перенос должен сохранить текущие пользовательские сценарии, интеграционные контракты и защиту учетных данных, одновременно приведя код и сборку к архитектуре монорепозитория.

## What Changes

- Перенести плагин в `packages/dsh-openai-codex-provider` с именем пакета `@kalex/dsh-openai-codex-provider`.
- Сохранить вход через OAuth по коду устройства ChatGPT, регистрацию модели OpenAI Codex, автоматическое обновление токена и существующие инструменты агента.
- Сохранить интерфейс настроек и его функции: выбор моделей, сведения об использовании и кредитах, применение карточек сброса после подтверждения, выбор системного или DSH-прокси.
- Привести реализацию к строгому TypeScript и структуре пакета DSH с отдельными слоями shared, host и client; использовать утвержденную сборку Vite и доступные компоненты `@kalex/dsh-core`.
- Обновить манифесты, зависимости, сборочные и проверочные сценарии, пакетные импорты и документацию под имя нового пакета.
- Сохранить совместимость runtime-идентификаторов, API, настроек и хранения учетных данных, если это необходимо для бесшовного обновления существующей установки.
- Не переносить Git-историю, установленные зависимости, результаты сборки, локальные учетные данные и секреты; исходный репозиторий оставить нетронутым.

- `openai-codex-provider`: вход ChatGPT, использование моделей OpenAI Codex, настройки и сведения об использовании в DSH.

## Impact

- Новый пакет `packages/dsh-openai-codex-provider` и связанные workspace-манифесты, конфигурация Vite, типизация, тесты и проверки выпуска.
- Хост-интеграция Cordis, LLM-адаптер, хранилище учетных данных, API настроек и Typed Remote-контракт клиентской части.
- Клиентский интерфейс, локализация, общие компоненты и токены дизайна из `@kalex/dsh-core`.
- Публичное имя пакета и команды установки; внутренние идентификаторы, которые нужны текущим установкам, остаются совместимыми.
- README, документация и сведения об авторстве и лицензии перенесенного проекта. Отдельный исходный репозиторий не изменяется.
