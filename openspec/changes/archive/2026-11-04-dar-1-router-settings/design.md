# Design

## Context

См. proposal.md и требования в specs/router-instruction-isolation/spec.md. Сопоставление путей и фильтрация контекста должны быть ограничены активным плагином, проверенными настройками пользователя и каталогом инструкций DSH в корне проекта.

## Goals / Non-Goals

**Goals:**
- Дать пользователю отдельные переключатели и многострочные поля ввода списков имен корневых файлов и каталогов, в которых можно свободно добавлять новые строки.
- Направлять совпавшие запросы чтения (по относительному или абсолютному пути внутри проекта) к соответствующему пути внутри каталога инструкций DSH без ошибок записи в защищенные аргументы вызова DSH.
- Исключать автоматическую подгрузку перенаправляемых корневых файлов инструкций встроенным механизмом DSH в контекст сессии, чтобы модель видела только правила из каталога роутера.
- Не раскрывать исходный файл, если включенное правило совпало, но безопасного назначения нет.

**Non-Goals:**
- Автоматически объединять правила DSH с правилами Cursor, Claude или других инструментов.
- Перенаправлять запросы к произвольным файлам за пределами выбранных корневых имен и каталогов.
- Изменять инструкции проекта или автоматически создавать недостающие файлы в каталоге инструкций DSH.

## Decisions

- Настраивать корневые файлы и каталоги раздельно. Корневое имя файла сопоставлять с одноименным файлом в каталоге инструкций DSH (`agents/`). Для выбранного каталога удалять его корневой префикс из запрошенного пути и сохранять оставшийся относительный путь внутри `agents/`. Так запрос `.cursor/rules/example.mdc` ведет к `agents/rules/example.mdc`.
- В интерфейсе настроек проекта хранить или обрабатывать текст многострочных полей списков имен так, чтобы переводы строк и пустые строки не удалялись во время набора текста, а очистка от пустых строк и пробелов выполнялась при сохранении настроек. Это устраняет ошибку, из-за которой нажатие клавиши ввода (`Enter`) сразу отбрасывалось.
- В перехватчике перед выполнением инструмента чтения (`tools/pre-execute`) не изменять свойство `file_path` внутри замороженного средой DSH объекта `exec.arguments`, а присваивать `exec.arguments` новый замороженный объект с подставленным путем назначения. Это устраняет ошибку `Cannot assign to read only property 'file_path'` в среде DSH.
- На шаге подготовки запроса к модели (`agent/pre-step`) при активном правиле перенаправления корневых файлов инструкций фильтровать системные сообщения встроенного загрузчика инструкций DSH (`agent-instructions`), удаляя из них блоки перенаправляемых корневых файлов проекта (например, `AGENTS.md`), но сохраняя служебные метаданные источника сообщения, чтобы загрузчик DSH не пытался повторно инжектировать эти файлы на следующих шагах.
- Применять правила только когда плагин включен, конфигурация прочитана и корректна, а соответствующий переключатель включен.
- Считать корневыми только файлы непосредственно в корневом каталоге проекта, а настроенные папки выбирать только среди непосредственных каталогов в корне.
- Нормализовать разделители, отклонять переходы за пределы каталога и проверять конечный путь назначения после разрешения символических ссылок. Если назначение отсутствует или выходит за пределы `agents/`, возвращать сообщение об ошибке без чтения исходного файла.
- Не запускать перенаправление повторно для файлов, уже находящихся внутри `agents/`.

## Risks / Trade-offs

- При фильтрации системных сообщений автоподгрузки DSH важно сохранять служебную отметку базового сообщения в случае, если в сообщении остаются другие инструкции (например, глобальные пользовательские инструкции), либо заменять блок перенаправляемого корневого файла без потери отметки базового состояния, чтобы не вызывать повторную подгрузку на каждом шаге.
- Недоступный целевой файл при включенном правиле приводит к отказу чтения исходника. Это предотвращает обход запрета и требует ясного сообщения с указанием отсутствующего назначения.

## Migration Plan

При выключенных значениях по умолчанию проекты сохраняют текущее поведение после обновления. Пользователь включает нужные правила и указывает корневые имена файлов или каталогов по одному в строке. Автоматическая миграция существующих настроек не требуется.
