# Предложение

## Зачем

Перенести плагин управления дополнительными каталогами из локальной папки `D:\GIT\DSH\dsh-plugin-addir` в текущий монорепозиторий DSH, чтобы развивать и проверять его рядом с остальными пакетами. Единственный источник переноса - текущее содержимое этой папки, включая локальные изменения и необходимые исходные файлы, не добавленные в Git. Код в этой папке изменялся; заменять его клоном, опубликованным пакетом или версией с GitHub запрещено. Ссылка на GitHub указывает только происхождение проекта. История Git исходного проекта не переносится. Происхождение проекта должно быть явно указано в README.

## Что изменится

Код плагина будет размещен в `packages/dsh-workspace-manager`, сохранит текущее поведение и будет приведен к обязательной архитектуре миграции DSH: строгий TypeScript, актуальная версия React, сборка Vite и разделение исходников на `src/shared`, `src/host` и `src/client`. Подходящие общие компоненты, хуки и контракты будут использоваться из `@kalex/dsh-core` либо выделяться туда. Имя пакета станет `@kalex/dsh-workspace-manager`. В README добавляется пометка, что проект является ответвлением исходного репозитория.

## Возможности

### Новые возможности
- `workspace-manager`: управление дополнительными каталогами рабочего пространства с сохранением текущего поведения плагина после переноса в монорепозиторий.

## Влияние

- Новый пакет: `packages/dsh-workspace-manager`.
- Структура исходников, манифесты pnpm, зависимости React и TypeScript, конфигурация Vite, типизации, тестирования и проверки выпуска.
- Имя пакета и связанные с ним импорты, идентификаторы и публикационные метаданные.
