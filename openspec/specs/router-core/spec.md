## Requirements

### Requirement: Поддержка `.mdc` и корректная обработка Frontmatter
Роутер ДОЛЖЕН находить файлы `.md` и `.mdc` без учета регистра расширения. Перед разбором YAML значения `glob`, `globs`, `path` и `paths` с неэкранированными спецсимволами ДОЛЖНЫ безопасно обрабатываться.

#### Scenario: Разбор `.mdc` с незаключенными в кавычки шаблонами
- **GIVEN** файл `.cursor/rules/typescript.mdc` с `globs: *.ts, src/**/*.tsx` и `alwaysApply: false`
- **WHEN** роутер загружает файл
- **THEN** он разбирает frontmatter без ошибки YAML
- **AND** нормализует шаблоны в `['*.ts', 'src/**/*.tsx']`
- **AND** сохраняет `alwaysApply: false`.

### Requirement: Поддержка полей `path`, `paths`, `glob` и `globs`
Роутер ДОЛЖЕН принимать одно значение или список значений в этих полях, разделять перечисления запятыми вне фигурных и квадратных скобок, нормализовать разделители путей и учитывать шаблоны исключения с префиксом `!`.

#### Scenario: Шаблон с альтернативами и исключением
- **GIVEN** правило с `globs: "src/**/*.{ts,tsx}, !src/**/*.spec.ts"`
- **WHEN** активный путь равен `src/components/Table.tsx`
- **THEN** правило выбрано
- **WHEN** активный путь равен `src/components/Table.spec.ts`
- **THEN** правило исключено.

#### Scenario: Сопоставление шаблона без каталога
- **GIVEN** правило с `globs: "*.mdc"`
- **WHEN** активный путь равен `.cursor/rules/general.mdc`
- **THEN** правило выбрано.

### Requirement: Обнаружение проектных источников по умолчанию
При настройке проекта по умолчанию роутер ДОЛЖЕН обнаруживать корневые инструкции, legacy-каталоги `agents/` или `.agents/`, а также источники `.cursor/`, `.claude/` и `.codex/`. Настройка проекта ДОЛЖНА позволять выбрать режим `strict`, `fallback` или `merge`; значение по умолчанию `merge`.

- `strict`: читать только заданный `instructionsRoot`.
- `fallback`: читать заданный `instructionsRoot`; если стандартный `agents/` отсутствует, использовать `.agents/` и одновременно сканировать vendor-источники. Если `.agents/` также отсутствует, сканировать только доступные vendor-источники.
- `merge`: объединять заданный legacy-корень (или `.agents/`, если стандартный `agents/` отсутствует) с корневыми и vendor-источниками.

#### Scenario: Проект с `.agents`, `.cursor` и корневым `AGENTS.md`
- **GIVEN** проект содержит `.agents/`, `.cursor/rules/*.mdc` и корневой `AGENTS.md`, но не содержит `agents/`
- **WHEN** роутер запускает обнаружение с настройками по умолчанию
- **THEN** состояние роутера содержит правила из `.agents/`, `.cursor/rules/` и `AGENTS.md`
- **AND** корневой `AGENTS.md` отмечен как всегда применяемый
- **AND** источники и причины выбора доступны через состояние роутера.

#### Scenario: Отсутствующие vendor-каталоги
- **GIVEN** проект не содержит `.claude/` или `.codex/`
- **WHEN** роутер сканирует проект
- **THEN** он продолжает обнаружение остальных источников без ошибки.
