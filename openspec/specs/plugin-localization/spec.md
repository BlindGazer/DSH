# Язык интерфейса плагинов

## Purpose

Пользователь управляет языком интерфейсов плагинов в настройках DSH. Общие средства локализации предоставляет `dsh-core`.

## Requirements

### Requirement: Открытые представления следуют языку оболочки

OpenAI Hub, Agents Router, Proxy Provider, Workspace Manager и Logger MUST обновлять переводы при изменении языка DSH без перезапуска и потери состояния представления.

#### Scenario: Переключение при открытом окне

- **WHEN** пользователь меняет язык DSH с английского на русский или обратно при открытой панели плагина
- **THEN** видимые подписи, подсказки и доступные имена обновляются, выбранная вкладка и введенные значения сохраняются

#### Scenario: Уже показанные данные и открытое меню

- **WHEN** пользователь меняет язык при открытом графике маршрутизатора или меню рабочей области
- **THEN** время существующих точек форматируется для нового языка без загрузки данных, а подпись и доступное имя пункта меню обновляются без повторного открытия

#### Scenario: Для языка нет перевода

- **WHEN** для активного языка DSH нет перевода подписи
- **THEN** подпись подставляется по цепочке резервных языков DSH, а даты и числа форматируются для активного языка

### Requirement: Локальный выбор языка отсутствует

Клиентские плагины MUST использовать язык оболочки DSH и не предоставлять отдельного поля выбора языка.

#### Scenario: Обновление со старой настройкой

- **WHEN** сохраненный ранее язык маршрутизатора или прокси-плагина отличается от языка DSH
- **THEN** интерфейс следует языку DSH, поле языка отсутствует, остальные настройки сохраняют значения
