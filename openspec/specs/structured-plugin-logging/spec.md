# structured-plugin-logging Specification

## Purpose

Хранение событий плагинов с очисткой данных, ограничением размера и безопасной сменой каталога.

## Requirements

### Requirement: Подготовка данных к записи

Данные MUST преобразовываться в JSON детерминированно. Функции, символы и неопределённые поля исключаются, `bigint` заменяется на `[BigInt]`, циклы на `[Circular]`, ошибки представлены именем и сообщением без стека.

#### Scenario: Несериализуемые данные
- **WHEN** данные содержат цикл, функцию или BigInt
- **THEN** JSON содержит маркеры вместо цикла и BigInt и не содержит функцию

### Requirement: Ограничения значений

В данных глубина MUST ограничиваться 8, более глубокие значения заменяются на `[Truncated]`. Строки MUST ограничиваться 4096 кодовыми точками Unicode. Отдельный предел 64 КиБ для поля данных не гарантируется: действует лимит всей записи.

#### Scenario: Особые числа
- **WHEN** данные содержат бесконечность, `NaN` или отрицательный ноль
- **THEN** записываются соответственно `null`, `null` и `0`

### Requirement: Очистка чувствительных данных

Поля MUST исключаться по подстрокам в ключе на любой глубине без учёта регистра: `token`, `authorization`, `cookie`, `password`, `secret`, `credential`, `api_key` и дополнительные ключи. Потребители MUST NOT передавать секреты в произвольных строках.

#### Scenario: Правило пути
- **WHEN** путь совпадает с полем или исходным индексом массива
- **THEN** значение удаляется, массив уплотняется

### Requirement: Проверка каталога

Каталог по умолчанию MUST находиться в профиле DSH (`dsh-logger`). Другой каталог MUST задаваться абсолютным путём. Сервер MUST проверять допустимый корень и отвергать символьную ссылку вместо выбранного каталога.

#### Scenario: Каталог вне профиля
- **WHEN** пользователь выбирает путь вне текущего профиля
- **THEN** смена требует явного подтверждения и серверной проверки

### Requirement: Один файл на пакет

Серверные и клиентские записи пакета MUST использовать один плоский файл. Имя строится заменой `/` на `-` и добавлением `.jsonl`. Повторный запрос для пакета и источника MUST использовать прежнюю привязку.

#### Scenario: Файл пакета
- **WHEN** сохраняются события сервера и клиента `@kalex/dsh-openai-hub`
- **THEN** обе строки находятся в `@kalex-dsh-openai-hub.jsonl` и различаются источником

### Requirement: Ограничение размера

Размер MUST измеряться в байтах UTF-8 с переводами строк. Логгер MUST уменьшать только данные, используя `[Truncated]`, и при нехватке места удалять старые полные строки. Если запись не помещается, она пропускается без прерывания операции потребителя.

#### Scenario: Превышение лимита
- **WHEN** новая запись не помещается в журнал
- **THEN** данные усекаются или запись пропускается; сохраняемый файл не превышает лимит

### Requirement: Межпроцессная блокировка

Запись MUST использовать единую блокировку каталога с ожиданием до 5 секунд. Блокировка старше 30 секунд MUST освобождаться, если нет живого процесса-владельца.

#### Scenario: Блокировка не освобождается
- **WHEN** ожидание истекло
- **THEN** запись пропускается

### Requirement: Замена и восстановление файла

Логгер MUST создавать временный файл в том же каталоге, сбрасывать его на диск и закрывать перед атомарной заменой. Если замена не удалась, исходный файл MUST оставаться неизменным.

#### Scenario: Оставшийся временный файл
- **WHEN** после сбоя начинается следующая запись
- **THEN** пригодный временный файл восстанавливается, если он не старее основного или основного нет; иначе временный файл удаляется

### Requirement: Очистка только после сохранения

Сервер MUST повторно сверять список удаления перед сохранением, а после него удалять только подтверждённые файлы учтённых пакетов. Принадлежность MUST проверяться по имени, типу файла и содержимому.

#### Scenario: Отмена или отказ сохранения
- **WHEN** смена каталога отменена или новое значение не сохранено
- **THEN** старые файлы не очищаются

### Requirement: Сохранение посторонних объектов

Корень, профиль, предок нового каталога, ссылки и неподтверждённые объекты MUST сохраняться. Пустой старый каталог MUST удаляться только нерекурсивно и при наличии подтверждения на его удаление.

#### Scenario: Только файлы журнала
- **WHEN** удалены все подтверждённые файлы и каталог не защищён
- **THEN** опустевший каталог удаляется

#### Scenario: Чужой файл
- **WHEN** в старом каталоге есть посторонний объект
- **THEN** он и каталог сохраняются

### Requirement: Сбой очистки

Ошибка очистки MUST возвращаться как предупреждение без отката сохранённой конфигурации.

#### Scenario: Не удалось удалить старый журнал
- **WHEN** новый каталог сохранён, но часть старых файлов удалить не удалось
- **THEN** пользователь получает предупреждение, а новый путь остаётся сохранённым
