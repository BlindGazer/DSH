# openai-hub Specification

## Purpose
OpenAI Hub предоставляет единый безопасный маршрут DSH для нескольких аккаунтов, объединяет их актуальные модели и показывает лимиты выбранного аккаунта без лишних сетевых запросов.

## Requirements

### Requirement: Единственная регистрация OpenAI Hub
Плагин MUST регистрировать один Host Remote-сервис и один LLM-маршрут `openai-hub`, не изменяя маршрут после авторизации.

#### Scenario: Запуск нового плагина
- **WHEN** новый пакет запускается в DSH
- **THEN** регистрируются `ServiceKey` `openai-hub`, namespace `openaiHub` и один маршрут `openai-hub`

### Requirement: Безопасное хранение аккаунтов
Плагин MUST хранить настройки аккаунтов в конфигурации, а секреты только в Credential Store с ключом `openai-hub-<authMethod>-<8-hex-hash(accountId)>`.

#### Scenario: Сохранение аккаунта
- **WHEN** пользователь завершает авторизацию
- **THEN** токены сохраняются в Credential Store, а метка и настройки модели в конфигурации без полного account id

### Requirement: Метка аккаунта
Пользователь MUST задавать lowercase ASCII label без пробелов до OAuth и иметь возможность изменить ее в карточке аккаунта.

#### Scenario: Переименование аккаунта
- **WHEN** пользователь сохраняет новую допустимую метку
- **THEN** публичные ID моделей пересобираются, credential record остается прежней, а старые ссылки истории становятся устаревшими

### Requirement: Актуальный объединенный каталог
Плагин MUST загружать каталог через авторизованный API после входа и по Refresh, объединять модели всех аккаунтов под одним маршрутом и проецировать ID как `<accountLabel>/<upstreamModelId>`. Группа провайдера MUST отображаться как `OpenAI Hub`; имя модели MUST оставаться `<accountLabel>/<upstreamModelId>`, а префикс `openai-hub/` может добавляться только внешним представлением DSH для списка субагентов.

#### Scenario: Добавление новой модели
- **WHEN** API возвращает новую модель
- **THEN** она появляется в списке с меткой аккаунта и может быть выбрана и отправлена с исходным upstream model id

#### Scenario: Ошибка каталога
- **WHEN** API-каталог недоступен
- **THEN** сохраняется последний успешный каталог, а до первого успешного ответа используется локальный каталог pi-ai с сообщением об ошибке обновления

### Requirement: Блоки моделей аккаунтов
Settings -> Models MUST показывать отдельный информационный блок и отдельное модальное окно для каждого аккаунта.

#### Scenario: Несколько аккаунтов
- **WHEN** настроены два аккаунта
- **THEN** оба блока отображаются последовательно и каждый открывает только свое модальное окно

### Requirement: Обновление лимитов
Автообновление лимитов MUST быть выключено для новых аккаунтов, сохраняться отдельно для каждого аккаунта и выполняться раз в пять минут при включении.

#### Scenario: Низкий ближайший лимит
- **WHEN** ближайший применимый лимит выбранной модели ниже 25 процентов
- **THEN** обновление выбранного аккаунта выполняется раз в минуту

#### Scenario: Скрытая страница
- **WHEN** страница DSH скрыта
- **THEN** сетевые обновления не выполняются, а после возврата видимости выполняется одно обновление

### Requirement: Лимиты в статус-баре чата
Статус-бар чата MUST показывать лимиты только выбранной модели этого провайдера и ее аккаунта.

#### Scenario: Другой провайдер
- **WHEN** выбрана модель другого провайдера
- **THEN** блок лимитов OpenAI Hub скрывается

### Requirement: Удаление аккаунта
Удаление MUST очищать Credential Store, настройки и модели аккаунта, не изменяя историю. Удаление последнего аккаунта MUST возвращать fresh-install состояние.

#### Scenario: Удаление последнего аккаунта
- **WHEN** пользователь подтверждает удаление последнего аккаунта
- **THEN** остается пустая секция с начальным действием добавления аккаунта, без старых credentials и настроек

### Requirement: Исправление фона модальных окон
Затронутые модальные окна MUST получать фон через Core theme tokens и фактический portal DOM в OpenAI Hub и workspace-manager.

#### Scenario: Открытие модального окна
- **WHEN** пользователь открывает любое затронутое модальное окно
- **THEN** карточка `dsh-modal-card` имеет видимый тематический фон в светлой и темной теме

### Requirement: Безопасность staged-рефакторинга
Исправления MUST удалять опасные credential debug logs и старые ссылки ProxyMode только после проверки их использования.

#### Scenario: Ошибка или OAuth
- **WHEN** выполняется OAuth или обработка ошибки
- **THEN** секреты не выводятся в консоль, UI или Remote-ответ
