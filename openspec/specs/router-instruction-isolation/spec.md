# router-instruction-isolation Specification

## Purpose

Дает пользователю возможность направлять агента к инструкциям DSH вместо файлов инструкций других инструментов и выбранных корневых файлов проекта, а также исключать их дублирующую автоподгрузку в контекст сессии. Ограничение действует только для активного плагина, корректных настроек и включенных пользователем правил.

## Requirements

### Requirement: Перенаправление применяется только при активном плагине и корректных настройках
Плагин MUST перенаправлять запросы чтения и исключать исходные инструкции из контекста сессии только если плагин включен, конфигурация прочитана и проверена, а соответствующее правило перенаправления включено.

#### Scenario: Плагин отключен
- **WHEN** агент запрашивает файл, совпадающий с настроенным правилом, но плагин выключен
- **THEN** запрос обрабатывается без перенаправления согласно обычным правилам чтения проекта

#### Scenario: Настройки отсутствуют или некорректны
- **WHEN** плагин включен, но настройки роутера отсутствуют или не проходят проверку
- **THEN** запросы обрабатываются согласно обычным правилам чтения проекта, перенаправление не применяется, а пользователь получает сообщение о некорректных настройках

#### Scenario: Плагин активен и правило включено
- **WHEN** плагин включен, настройки корректны и соответствующее правило включено
- **THEN** совпавший запрос и контекст сессии обрабатываются согласно правилам изоляции корневых файлов или каталогов

### Requirement: Пользователь может настроить перенаправление и изоляцию корневых файлов инструкций
Плагин MUST позволять отдельно включать перенаправление корневых файлов инструкций и редактировать список их имен по одному на строке. Имена MUST сопоставляться только с файлами непосредственно в корне проекта независимо от способа указания пути при чтении. Исходный файл MUST NOT попадать в контекст сессии через чтение или автоматическую загрузку инструкций рабочей области DSH.

#### Scenario: Построчное добавление имен в настройках проекта
- **WHEN** пользователь редактирует список корневых файлов или корневых каталогов и нажимает клавишу перевода строки, чтобы добавить имя
- **THEN** поле ввода переносит курсор на новую строку и позволяет указать несколько имен, а при сохранении пустые строки удаляются и настройки сохраняются без ошибок проверки

#### Scenario: Чтение корневого файла по относительному или абсолютному пути
- **WHEN** активный плагин получает запрос на чтение корневого файла из списка по относительному имени или полному пути внутри проекта
- **THEN** агент получает содержимое одноименного файла из каталога `agents/`, а исходное содержимое корневого файла не передается

#### Scenario: Исключение перенаправляемого корневого файла из базового контекста сессии
- **WHEN** правило перенаправления корневых файлов включено и DSH формирует контекст инструкций рабочей области для шага сессии
- **THEN** содержимое корневого файла из списка не попадает в контекст агента в обход роутера, а агент видит правила из каталога `agents/`

#### Scenario: Перенаправление корневого файла выключено
- **WHEN** агент запрашивает файл из списка, а правило перенаправления корневых файлов выключено
- **THEN** запрос обрабатывается без подмены согласно обычным правилам чтения проекта

#### Scenario: Запрашивается неуказанный корневой файл
- **WHEN** агент запрашивает корневой файл, имя которого отсутствует в списке
- **THEN** плагин не перенаправляет запрос по правилу корневых файлов

#### Scenario: Совпадающее имя находится во вложенном каталоге
- **WHEN** агент запрашивает вложенный файл, имя которого совпадает с именем из списка корневых файлов
- **THEN** плагин не перенаправляет запрос по правилу корневых файлов

### Requirement: Пользователь может настроить перенаправление каталогов инструкций
Плагин MUST позволять включать перенаправление выбранных корневых каталогов инструкций и сопоставлять путь файла относительно каждого такого каталога с тем же относительным путем внутри `agents/`.

#### Scenario: Запрошен файл в выбранном каталоге
- **WHEN** активный плагин получает запрос `.cursor/rules/example.mdc`, каталог `.cursor` выбран и правило перенаправления каталогов включено
- **THEN** агент получает содержимое `agents/rules/example.mdc`, где `rules/example.mdc` является путем относительно выбранного каталога `.cursor`

#### Scenario: Запрошен файл в невыбранном каталоге
- **WHEN** агент запрашивает файл из каталога, который не выбран, или правило перенаправления каталогов выключено
- **THEN** плагин не перенаправляет запрос по правилу каталогов

#### Scenario: Несколько выбранных каталогов содержат одинаковый относительный путь
- **WHEN** агент запрашивает файлы с одинаковым относительным путем в двух выбранных каталогах
- **THEN** оба запроса направляются к одному и тому же соответствующему пути внутри `agents/`

### Requirement: Перенаправление не раскрывает исходное содержимое при недоступном или небезопасном назначении
Плагин MUST проверять нормализованный путь назначения, включая конечную цель после разрешения ссылок файловой системы. Если назначение отсутствует или находится за пределами `agents/`, плагин MUST NOT передавать исходное содержимое.

#### Scenario: Файл назначения отсутствует
- **WHEN** запрос совпадает с включенным правилом, но соответствующий файл внутри `agents/` отсутствует
- **THEN** исходное содержимое не передается, а пользователь получает сообщение о недоступной инструкции DSH

#### Scenario: Путь назначения выходит за пределы каталога инструкций
- **WHEN** путь назначения содержит переход за пределы `agents/`, является абсолютным или его конечная цель после разрешения ссылки находится за пределами `agents/`
- **THEN** плагин отклоняет перенаправление, не передает исходное содержимое и сообщает о недопустимом назначении

#### Scenario: Запрашивается файл, уже расположенный в каталоге инструкций
- **WHEN** агент запрашивает файл внутри `agents/`, к которому уже направляется другой запрос
- **THEN** плагин передает этот файл без повторного перенаправления
