# Действующие спецификации пакетов DSH

Этот раздел описывает пакеты репозитория `@kalex`, а не все функции DeepSeek Harness. Здесь зафиксированы поддерживаемое поведение, его ограничения и обязательные правила разработки. Незавершенные изменения и история находятся отдельно в `openspec/changes/` и не являются перечнем доступных функций.

## Устанавливаемые плагины

Минимальная версия DSH для этих плагинов - `0.2.2-rc.5`. Для установки OpenAI Hub через командную строку требуется Node.js `22.19.0` или новее. Установкой в профиль Desktop управляет приложение.

| Пакет | Назначение | Спецификация |
| --- | --- | --- |
| `dsh-agents-router` | Выбор правил и навыков проекта для сессии агента | [Маршрутизация](router-core/spec.md), [изоляция инструкций](router-instruction-isolation/spec.md) |
| `dsh-proxy-provider` | Прокси для запросов провайдеров моделей | [Профили, выбор маршрута и ограничения](proxy-provider/spec.md) |
| `dsh-workspace-manager` | Подключенные каталоги, рабочие деревья Git и запуск VS Code | [Рабочая область](workspace-manager/spec.md) |
| `dsh-openai-hub` | Модели OpenAI Codex, аккаунты ChatGPT и лимиты | [OpenAI Hub](openai-hub/spec.md) |
| `dsh-logger` | Настройки и запись структурированных журналов плагинов | [Сервис](global-plugin-logger/spec.md), [управление](logger-management-ui/spec.md), [запись и защита данных](structured-plugin-logging/spec.md) |

## Библиотеки и общие правила

| Область | Спецификация |
| --- | --- |
| `dsh-core`: общие компоненты, темы и средства локализации | [Дизайн-система](theme-consistency/spec.md), [язык интерфейса](plugin-localization/spec.md) |
| `dsh-logger-core`: общий контракт журналирования | [Контракт и интеграция](global-plugin-logger/spec.md) |
| Разработка, диагностика, приемка и выпуск | [Архитектура и поддержка](module-architecture/spec.md) |

`MUST` обозначает обязательное требование. Сценарии под требованиями показывают, как проверить результат. Проверка `openspec validate --specs` подтверждает структуру документов, но не заменяет тесты реализации.
